# MetaCTF – Monthly Competitions

This folder contains write-ups and notes from ongoing participation in **MetaCTF’s monthly cybersecurity competitions**. Each event features a mix of challenges across web exploitation, reverse engineering, cryptography, forensics, and general security concepts.

---

## Overview

**Objective:** Strengthen applied cybersecurity skills through recurring competitive scenarios.  
**Format:** Timed CTF events with individual and team-based problem solving.  
**Focus Areas:** Web, binary, crypto, forensics, and OSINT challenges.

---

## Skills Developed

- Vulnerability identification and exploitation  
- Log and packet analysis  
- Reverse engineering and deobfuscation  
- Cryptographic reasoning and data recovery  
- Collaboration under timed conditions  

---

> Ongoing participation in MetaCTF events supports continuous skill growth and real-world problem-solving experience across multiple cybersecurity domains.
