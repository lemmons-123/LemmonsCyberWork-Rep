# PicoCTF – Challenge Write-Ups

This folder contains selected write-ups from various **PicoCTF** challenges completed as part of personal cybersecurity skill development. These exercises covered binary exploitation, web vulnerabilities, cryptography, and forensics.

---

## Overview

**Platform:** PicoCTF  
**Format:** Individual capture-the-flag challenges designed to reinforce applied cybersecurity fundamentals through hands-on problem solving.  

---

## Sample Challenges

- **n0s4n1ty1:** Reverse engineered a simple binary to identify hidden flag logic using Ghidra and string analysis.  
- **PIE_TIME:** Exploited a position-independent executable (PIE) to bypass memory randomization and retrieve the flag.  
- **SSTI1:** Performed a server-side template injection (SSTI) attack to achieve code execution and extract sensitive data.  
- **DISKO1:** Conducted forensic recovery on a corrupted disk image to locate embedded flag fragments.  

---

## Skills Demonstrated

- Binary exploitation and reverse engineering  
- Web application vulnerability analysis  
- Cryptography and encoding challenges  
- Forensic image analysis and data recovery  
- Scripting and automation for CTF workflows
