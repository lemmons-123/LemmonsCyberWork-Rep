# REKCAH Comic CTFs

This folder contains CTF challenges from the **BlackHills Information Security** and **REKCAH** authored/designed comic series *"The Future is *****"*. 

I won these comics in a raffle while attending a webinar and was gifted all volumes(1-7). Expect to see more write-ups added soon as I work through the challenges!

## Challenge Types

The CTFs embedded in these comics cover a variety of cybersecurity skills, including:

- **Decryption & Cryptography** - Breaking ciphers and encoding schemes
- **Packet Analysis** - Network traffic inspection and protocol analysis
- **Binary Reverse Engineering** - Analyzing compiled executables and understanding low-level code
- **Website Tampering** - Web exploitation and manipulation techniques
