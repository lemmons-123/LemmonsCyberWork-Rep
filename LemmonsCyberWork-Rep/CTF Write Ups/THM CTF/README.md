# TryHackMe – Industrial Intrusion Team Event

This folder documents participation in the **Industrial Intrusion** team-based cybersecurity event hosted on **TryHackMe**. The challenge simulated a targeted attack on an industrial control system (ICS) network, requiring participants to investigate, analyze, and respond to multiple stages of intrusion.

---

## Overview

**Objective:** Identify and mitigate a multi-stage intrusion targeting an industrial environment through network analysis, log review, and exploitation tracing.  
**Format:** Team-based CTF event combining offensive and defensive tasks.  
**Environment:** Simulated ICS network with segmented OT and IT layers.

---

## Key Tasks

- **Task 19 – Salt:** Investigated compromised configuration files and extracted credentials from a misconfigured SaltStack deployment.  
- **Task 28 – Start:** Conducted initial network reconnaissance and identified exposed services leading to lateral movement opportunities.  

---

## Skills Demonstrated

- ICS network reconnaissance and segmentation analysis  
- Exploitation of misconfigured management services (SaltStack)  
- Log correlation and intrusion timeline reconstruction  
- Team-based incident response and evidence documentation  

---

> This event reinforced practical skills in industrial cybersecurity, blending red-team tactics with blue-team analysis to simulate real-world OT network compromise scenarios.
