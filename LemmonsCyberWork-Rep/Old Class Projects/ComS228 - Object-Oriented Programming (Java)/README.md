# ComS 228 – Object-Oriented Programming (Java)

This folder contains recovered coursework from *ComS 228: Object-Oriented Programming* at Iowa State University. The course focused on Java programming fundamentals, data structures, and algorithmic problem solving using object-oriented design principles.

## Archived Project: Message Reconstruction

**Project Title:** Archived Message Reconstruction  
**Objective:** Rebuild a compressed message using a binary tree–based decoding algorithm.  
**Key Concepts:** Recursion, tree traversal, file I/O, and string parsing.

### Overview
The assignment required implementing a `MsgTree` class to:
- Reconstruct a binary tree from a preorder traversal string  
- Decode a bitstring representing an archived message  
- Print each character’s binary encoding and the decoded message  

The program demonstrated understanding of:
- Recursive data structure construction  
- Binary tree traversal logic  
- Clean console output formatting and modular Java design
