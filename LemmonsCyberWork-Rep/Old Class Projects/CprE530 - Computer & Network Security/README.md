# CprE 430/530 – Computer and Network Security

This folder contains recovered lab assignments from *CprE 430/530: Computer and Network Security* at Iowa State University. The course emphasized system exploitation fundamentals, secure communication protocols, and defensive mechanisms.

---

## Lab 1 – Buffer Overflow and ASLR

**Objective:** Demonstrate how memory corruption vulnerabilities occur and how Address Space Layout Randomization (ASLR) mitigates them.  

**Highlights:**  
- Wrote and executed C programs vulnerable to buffer overflow  
- Observed stack memory layout and instruction pointer control  
- Tested ASLR behavior by comparing randomized memory addresses across runs  
- Documented exploitation attempts and mitigation results  

**Skills:**  
Memory safety analysis, Linux debugging, exploitation fundamentals, ASLR verification  

---

## Lab 2 – Network Mail Protocols

**Objective:** Analyze the structure and security of email transmission protocols (SMTP, POP3, IMAP).  

**Highlights:**  
- Mapped client-server communication paths using SMTP and IMAP  
- Captured and inspected email traffic with Wireshark  
- Identified plaintext credential exposure and protocol weaknesses  
- Discussed encryption and authentication improvements such as STARTTLS and SSL/TLS  

**Skills:**  
Network protocol analysis, packet inspection, secure communication design, protocol hardening  

---

> These labs provided foundational experience in both system-level and network-layer security, reinforcing practical understanding of exploitation, mitigation, and secure protocol design.
