# CprE 538 – Digital Forensics

This folder contains recovered coursework from *CprE 538: Digital Forensics* at Iowa State University. The course focused on forensic investigation techniques, evidence recovery, and analysis of digital artifacts using professional forensic tools.

---

## Project 2 – Forensic Case Analysis

**Objective:** Conduct a digital investigation to identify hidden evidence and reconstruct user activity from a provided forensic image.  

**Tools Used:** Autopsy, FTK Imager, gzip utilities, PDF metadata viewers  

### Overview
The project simulated a forensic case involving multiple file types and hidden data. The task was to locate five “figures” (envelope labels) containing contact information and identify the sender’s alias through file and metadata analysis.  

### Key Findings
- Discovered embedded evidence in `manual.pdf` revealing the alias **Emma White**  
- Extracted compressed data from `mypuppy.gz` and analyzed its contents  
- Used Autopsy’s Overview and File Extension tabs to locate relevant artifacts  
- Documented all findings with screenshots and supporting analysis  

### Skills Demonstrated
- File system and metadata analysis  
- Evidence extraction from compressed and document files  
- Forensic workflow documentation and reporting  
- Use of professional forensic toolkits
