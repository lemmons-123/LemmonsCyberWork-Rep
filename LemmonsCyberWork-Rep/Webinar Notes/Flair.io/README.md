# Flair.io Webinars Notes Collection

This repository houses notes and summaries from various Flair.io webinars I’ve attended. Each folder focuses on a different session or instructor, with emphasis on practical, actionable takeaways. I’m revising these over time as I revisit the material or apply it in hands-on labs.

## Completed Write-Ups:
- **Intro to the Ransomware Ecosystem — Tammy Harper**
  Comparative analysis of Conti and LockBit, insights from Bassterlord’s manuals, and an overview of modern ransomware trends and negotiation psychology.

- **Active Directory Security and Entra ID — Mike Iaconianni**
  Deep dive into AD security fundamentals, the Enterprise Access Model (Tiering), common attacks like Kerberoasting and Mimikatz, and strategies for securing Entra ID environments.

## Goal:
To build a concise, research-driven reference for understanding ransomware ecosystems, negotiation dynamics, and attacker psychology—useful for CTI analysts, IR teams, and security researchers.
